Expected CSV Format Specification

The CSV file must contain a header row. Phone numbers and Telegram IDs are accepted:

Name,Phone,Consent_Status,Tags
Rohan Sharma,+919876543210,opted_in,channel:whatsapp,vip,rates
Pooja Verma,9123456789,opted_in,channel:whatsapp,daily_rates

  • Automatic Normalization: Phone numbers without country code default to E.164 (+91...).
  • Telegram IDs: Use prefix tg_ (e.g. tg_123456789) for Telegram bot subscribers.
  • Duplicate Protection: Existing phone records are preserved; duplicates are skipped without throwing errors.
